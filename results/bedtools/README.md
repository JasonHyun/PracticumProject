These are the outputs from using bedtools intersect between mapped mouse tissues with human tissues. 

The conserved folder includes outputs of across-species-same-tissue and across-tissues-same-species analysis. 

The unique folder includes outputs exclusive to each of human liver, human pancreas, mouse liver, and mouse pancreas (using the -v flag from bedtools intersect). 

The simplified folder includes all of the outputs listed above, reduced to just include the first three columns for the sake of using them as inputs for GREAT analysis.
