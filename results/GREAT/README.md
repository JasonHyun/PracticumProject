These are the outputs from conducting GREAT analysis with each of simplified conserved and unique regions, found in results/bedtools/simplified. The output themselves are saved as pdf files, as the analysis is done through a web browser. 

The enhancer and promoter percentage values for each context (e.g., tissue_human), were computed with the barplots of absolute distance to TSS, where we defined bins within 5 kb of TSS as promoters and the rest as enhancers.
